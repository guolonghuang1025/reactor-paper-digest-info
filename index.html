Reactor Paper Digest

个人使用的熔盐堆、OpenFOAM 与反应堆热工水力论文日报。程序在 GitHub Actions 运行，将公开论文信息与原始摘要发送给已配置的本人 Gmail 邮箱。不调用 OpenAI API。

隐私政策

生效日期：2026-10-15。

Google 数据访问仅限用户授权的邮箱身份信息和代表用户发送电子邮件的权限。不读取、搜索或下载收件箱邮件、附件、通讯录或日历。

邮箱身份用于确认发信账号与配置一致；发信权限仅用于论文日报及用户请求的配置测试。Google OAuth 凭据存储在受限本地文件与专用私有 GitHub 仓库的 Actions Secrets 中，供工作流调用 Gmail API。程序不将凭据提交到 Git 仓库、不在日志打印凭据。

公开论文元数据、原始摘要、阅读计划和发送状态保存于私有仓库；邮件内容通过 Gmail 交付。GitHub 与 Google 分别处理托管运行和邮件服务所需的数据。该应用不出售 Google 用户数据，不将其用于广告、模型训练或与日报无关的用途。

Google 用户数据的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。

用户可在 Google 账号的第三方连接设置撤销授权，并在仓库关闭 DIGEST_ENABLED、移除 GMAIL_OAUTH_JSON Secret，停止发送。删除受限本地授权文件与私有仓库中的发送记录可移除应用保存的数据；Git 历史与平台备份依各平台保留规则处理。

本应用仅供账号持有人个人使用。联系：账号持有人，可通过本网站所属 GitHub 账号的公开联系方式联系。
